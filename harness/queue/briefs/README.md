# File des briefs CityLab

Un lot exécutable a **un** brief ici. Hermes propose ; Claude Code rédige
le brief et les critères ; Cursor exécute ; le propriétaire fusionne.

Une proposition sous `hermes/propositions/` n'est pas un brief.

## Forme minimale

```
harness/queue/briefs/NNN-slug/
  brief.md          instruction unique de l'exécutant
  eval-rubric.md    critères de la revue Claude
```

Le brief cite l'identifiant de roadmap (`M3-FH-05`, `META-PILOT-01`, …)
sans paraphraser toute la roadmap. Il distingue laboratoire
(`LocalCitySimulation`) et production (`sim/` ForgeHistory).
